Follow one coin

What happens when you save “52,40 € at REWE”

You type 52,40, pick Groceries and press Save.

The shop window turns “52,40” into 5240 cents. Whole cents never get rounding errors, so 0,10 + 0,20 is always exactly 0,30. It puts the amount in a parcel JSON and sends it to /api/transactions along with your wristband session cookie.

The shopkeeper checks the wristband: is this really you? Then it checks the parcel zod: is the amount above zero, is the date real, and do the account and category belong to your family? If anything is wrong, it sends back a clear message instead of saving.

The translator Prisma writes the line into the notebook SQLite.

The shopkeeper answers “saved”. For the Budget page, it does the 50/30/20 maths: income, Essentials, Fun, Future You, unused amount and savings rate. INR becomes EUR using your monthly rate.

The shop window TanStack Query refreshes the list, your account balance and the budget bars, so you see the new numbers straight away.

Two ways to run it

The lunchbox and the workshop

The same code runs in two ways. One is for using the app every day, the other is for building it.

The lunchbox: daily use

http://localhost:8080

Docker packs the finished app and everything it needs into one sealed box called a container. Your notebook stays outside the box, in your data/ folder, so a new box never loses your money data.

  • One box runs the shopkeeper, and the shopkeeper also hands out the shop window.
  • It starts by itself when Docker starts.
docker compose up -d --build

The workshop: building new features

http://localhost:5173 → :3001

Two helpers run side by side. Vite shows the shop window and updates it the moment code changes. The shopkeeper runs on port 3001 with its own practice notebook, data/dev.db.

  • Your real data is never touched while building.
  • The Dev Container is a ready-made workshop box for VS Code on any laptop.
npm run dev

Safety guards

How your money data is kept safe

A lock on the door

Your password is never stored, only a scrambled fingerprint of it argon2id.

A wristband

After you log in, the browser wears a secret wristband httpOnly cookie. The page’s own scripts can’t read it, and other websites can’t use it.

Only your family

Every question to the notebook says “only this family’s pages”. Other families get “not found”.

Only this laptop

The app listens on 127.0.0.1, so other devices can’t reach it until we open it up for your family.

Too many wrong guesses

After 10 wrong logins in a minute, the door stays shut for a while rate limit.

Copies before changes

Before every upgrade, the notebook is copied into backups/.
