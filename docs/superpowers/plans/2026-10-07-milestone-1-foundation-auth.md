# Milestone 1 — Foundation, Auth & Family Members Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A runnable myPiggyBank skeleton (plus a runtime Docker image and a VS Code dev container): npm-workspace repo, Fastify API with Prisma/SQLite, secure email/password login with server-side sessions, family-member management, and a React app shell (login, register, dashboard placeholder, settings → members).

**Architecture:** Root npm workspace with `backend/` (Fastify 5 + TypeScript + Prisma 6 on SQLite) and `frontend/` (React 19 + Vite + Tailwind 4 + TanStack Query). In dev, Vite (5173) proxies `/api` to Fastify (3001). In production mode, Fastify serves the built frontend on one port. Every domain row carries `familyId`; every query filters by the logged-in user's family.

**Tech Stack:** Node 22, TypeScript (strict), Fastify 5, @fastify/cookie, @fastify/helmet, @fastify/rate-limit, @fastify/static, Prisma 6 (SQLite), zod 4, @node-rs/argon2, Vitest 3, React 19, React Router 7, TanStack Query 5, Tailwind CSS 4, lucide-react, ESLint 9 (flat config), Prettier.

**Spec:** `docs/superpowers/specs/2026-10-07-mypiggybank-v1-design.md`

## Global Constraints

- Node.js **22 LTS** (`.nvmrc` = `22`), installed via nvm, no sudo.
- TypeScript `strict: true` in every package.
- All IDs are UUIDs (`@default(uuid())`); tables have `createdAt`/`updatedAt` where rows are editable.
- Money (later plans) is integer minor units + ISO currency, default `EUR`. No floats in storage.
- Every domain query is scoped by the session user's `familyId`; another family's row ⇒ **404**, never 403 (no existence leak).
- API response shape: success `{ "data": ... }`; failure `{ "error": { "code", "message", "details?" } }`.
- Passwords: argon2id (`memoryCost: 19456, timeCost: 2, parallelism: 1`). Minimum length 10.
- Session cookie `pb_session`: httpOnly, `SameSite=Strict`, `Secure` when `COOKIE_SECURE=true`, path `/`. Token = 32 random bytes; DB stores only its SHA-256.
- Server binds `127.0.0.1` by default (`HOST` env).
- Secrets/data never committed: `.env`, `data/`, `backups/`, `*.db` are git-ignored. `.env.example` is committed.
- Git author for this repo: `suryasoundar96@gmail.com` (already set locally). Commits end with `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`. Never push unless the user asks.

## Review Focus

1. Login with a wrong password and with an unknown email must return the **identical** 401 body (no account enumeration) — test in Task 3.
2. Email with mixed case / surrounding spaces (`" Surya@Example.COM "`) registers as `surya@example.com`, logs in case-insensitively, and a second registration differing only in case is a 409 — test in Task 3.
3. A user from family B using family A's member id on PUT/DELETE must get 404 and A's data must be unchanged — test in Task 4.
4. An expired session cookie must behave as logged-out (401) and the session row must be removed — test in Task 3.
5. Repeated login attempts beyond the limit must return 429 `RATE_LIMITED` in the standard error shape — test in Task 3.

```ts
import { z } from 'zod';

const EnvSchema = z.object({
  NODE_ENV: z.enum(['development', 'production', 'test']).default('development'),
  HOST: z.string().default('127.0.0.1'),
  PORT: z.coerce.number().int().positive().default(3001),
  DATABASE_URL: z.string().min(1),
  COOKIE_SECURE: z.stringbool().default(false),
  ALLOW_REGISTRATION: z.stringbool().default(true),
  SESSION_DAYS: z.coerce.number().int().positive().default(30),
});

export type Config = z.infer<typeof EnvSchema>;

export function loadConfig(env: NodeJS.ProcessEnv = process.env): Config {
  const result = EnvSchema.safeParse(env);
  if (!result.success) {
    throw new Error(`Invalid environment configuration:\n${z.prettifyError(result.error)}`);
  }
  return result.data;
}
```

```ts
export function parse<T extends z.ZodType>(schema: T, data: unknown): z.output<T> {
  const result = schema.safeParse(data);
  if (!result.success) {
    throw new AppError(
      400,
      'VALIDATION_ERROR',
      'Invalid request',
      result.error.issues.map((i) => ({ path: i.path.join('.'), message: i.message })),
```

`backend/src/auth/sessions.ts`
```ts
import { createHash, randomBytes } from 'node:crypto';
import type { PrismaClient } from '@prisma/client';

export const SESSION_COOKIE = 'pb_session';

export type AuthUser = {
  id: string;
  email: string;
  name: string;
  role: string;
  familyId: string;
  memberId: string | null;
};

const hashToken = (token: string) => createHash('sha256').update(token).digest('hex');

export function toAuthUser(
  u: { id: string; email: string; name: string; role: string; familyId: string },
  memberId: string | null,
): AuthUser {
  return { id: u.id, email: u.email, name: u.name, role: u.role, familyId: u.familyId, memberId };
}

export async function createSession(prisma: PrismaClient, userId: string, days: number) {
  const token = randomBytes(32).toString('base64url');
  const expiresAt = new Date(Date.now() + days * 86_400_000);
  await prisma.session.create({ data: { tokenHash: hashToken(token), userId, expiresAt } });
  return { token, expiresAt };
}

export async function findSessionUser(prisma: PrismaClient, token: string): Promise<AuthUser | null> {
  const session = await prisma.session.findUnique({
    where: { tokenHash: hashToken(token) },
    include: { user: { include: { member: true } } },
  });
  if (!session) return null;
  if (session.expiresAt <= new Date()) {
    await prisma.session.deleteMany({ where: { id: session.id } });
    return null;
  }
  return toAuthUser(session.user, session.user.member?.id ?? null);
}

export async function deleteSession(prisma: PrismaClient, token: string): Promise<void> {
  await prisma.session.deleteMany({ where: { tokenHash: hashToken(token) } });
}
```

```ts
import Fastify, { type FastifyError, type FastifyInstance } from 'fastify';
import cookie from '@fastify/cookie';
import helmet from '@fastify/helmet';
import rateLimit from '@fastify/rate-limit';
import fastifyStatic from '@fastify/static';
import type { PrismaClient } from '@prisma/client';
import type { Config } from './config.js';
import { AppError } from './lib/errors.js';
import { SESSION_COOKIE, findSessionUser } from './auth/sessions.js';
import { healthRoutes } from './routes/health.js';

export type AppConfig = Pick<Config, 'COOKIE_SECURE' | 'ALLOW_REGISTRATION' | 'SESSION_DAYS'>;

export interface AppOptions {
  prisma: PrismaClient;
  config: AppConfig;
  logger?: boolean;
  /** Absolute path to frontend/dist; when set, the SPA is served from Fastify. */
  frontendDist?: string;
  loginRateLimit?: { max: number; timeWindow: string };
}

export async function buildApp(opts: AppOptions): Promise<FastifyInstance> {
  const app = Fastify({ logger: opts.logger ?? false });

  app.decorate('prisma', opts.prisma);
  app.decorate('appConfig', opts.config);
  app.decorateRequest('user', null);

  // Only JSON bodies are accepted; text/plain is a CORS-"simple" type usable for CSRF.
  app.removeContentTypeParser('text/plain');

  await app.register(helmet);
  await app.register(cookie);
  await app.register(rateLimit, {
    global: false,
    errorResponseBuilder: () =>
      new AppError(429, 'RATE_LIMITED', 'Too many attempts, please try again later'),
  });

  app.setErrorHandler((err: FastifyError, req, reply) => {
    if (err instanceof AppError) {
      return reply.status(err.statusCode).send({
        error: { code: err.code, message: err.message, details: err.details },
      });
    }
    if (err.statusCode && err.statusCode >= 400 && err.statusCode < 500) {
      return reply.status(err.statusCode).send({ error: { code: 'BAD_REQUEST', message: err.message } });
    }
    req.log.error(err);
    return reply.status(500).send({ error: { code: 'INTERNAL_ERROR', message: 'Something went wrong' } });
  });

  app.addHook('onRequest', async (req) => {
    const token = req.cookies[SESSION_COOKIE];
    req.user = token ? await findSessionUser(app.prisma, token) : null;
  });

  await app.register(
    async (api) => {
      await api.register(healthRoutes);
    },
    { prefix: '/api' },
  );

  if (opts.frontendDist) {
    await app.register(fastifyStatic, { root: opts.frontendDist, wildcard: false });
  }

  app.setNotFoundHandler((req, reply) => {
    if (opts.frontendDist && req.method === 'GET' && !req.url.startsWith('/api')) {
      return reply.type('text/html').sendFile('index.html');
    }
    return reply.status(404).send({ error: { code: 'NOT_FOUND', message: 'Route not found' } });
```

```ts
import { hash, verify } from '@node-rs/argon2';
import { Prisma, type PrismaClient } from '@prisma/client';
import { z } from 'zod';
import { AppError } from '../lib/errors.js';
import { toAuthUser, type AuthUser } from '../auth/sessions.js';

const email = z.string().trim().toLowerCase().max(254).pipe(z.email('Enter a valid email address'));

export const RegisterInput = z.object({
  name: z.string().trim().min(1, 'Name is required').max(100),
  email,
  password: z.string().min(10, 'Password must be at least 10 characters').max(200),
  familyName: z.string().trim().min(1).max(100).optional(),
});

export const LoginInput = z.object({
  email,
  password: z.string().min(1, 'Password is required').max(200),
});

const ARGON2 = { memoryCost: 19456, timeCost: 2, parallelism: 1 };

const emailTaken = () =>
  new AppError(409, 'EMAIL_TAKEN', 'An account with this email already exists');
const invalidCredentials = () =>
  new AppError(401, 'INVALID_CREDENTIALS', 'Invalid email or password');

// Verified against when the email is unknown so both paths cost the same time.
let dummyHash: Promise<string> | undefined;

export async function registerUser(
  prisma: PrismaClient,
  input: z.output<typeof RegisterInput>,
): Promise<AuthUser> {
  if (await prisma.user.findUnique({ where: { email: input.email } })) throw emailTaken();
  const passwordHash = await hash(input.password, ARGON2);
  try {
    return await prisma.$transaction(async (tx) => {
      const family = await tx.family.create({
        data: { name: input.familyName ?? `${input.name}'s family` },
      });
      const user = await tx.user.create({
        data: { familyId: family.id, email: input.email, passwordHash, name: input.name, role: 'owner' },
      });
      const member = await tx.familyMember.create({
        data: { familyId: family.id, name: input.name, userId: user.id },
      });
      return toAuthUser(user, member.id);
    });
  } catch (e) {
    if (e instanceof Prisma.PrismaClientKnownRequestError && e.code === 'P2002') throw emailTaken();
    throw e;
  }
}

export async function loginUser(
  prisma: PrismaClient,
  input: z.output<typeof LoginInput>,
): Promise<AuthUser> {
  const user = await prisma.user.findUnique({
    where: { email: input.email },
    include: { member: true },
  });
  if (!user) {
    dummyHash ??= hash('timing-equaliser-password', ARGON2);
    await verify(await dummyHash, input.password);
    throw invalidCredentials();
  }
  if (!(await verify(user.passwordHash, input.password))) throw invalidCredentials();
  return toAuthUser(user, user.member?.id ?? null);
}
```

```ts
import type { FastifyPluginAsync, FastifyReply } from 'fastify';
import { AppError } from '../lib/errors.js';
import { parse } from '../lib/validate.js';
import { SESSION_COOKIE, createSession, deleteSession } from '../auth/sessions.js';
import { currentUser, requireAuth } from '../auth/requireAuth.js';
import { LoginInput, RegisterInput, loginUser, registerUser } from '../services/authService.js';

export interface AuthRoutesOptions {
  loginRateLimit: { max: number; timeWindow: string };
}

export const authRoutes: FastifyPluginAsync<AuthRoutesOptions> = async (app, opts) => {
  const startSession = async (reply: FastifyReply, userId: string) => {
    const { token, expiresAt } = await createSession(app.prisma, userId, app.appConfig.SESSION_DAYS);
    reply.setCookie(SESSION_COOKIE, token, {
      path: '/',
      httpOnly: true,
      sameSite: 'strict',
      secure: app.appConfig.COOKIE_SECURE,
      expires: expiresAt,
    });
  };
  const limited = { rateLimit: opts.loginRateLimit };

  app.post('/auth/register', { config: limited }, async (req, reply) => {
    if (!app.appConfig.ALLOW_REGISTRATION) {
      throw new AppError(403, 'REGISTRATION_DISABLED', 'Registration is disabled');
    }
    const user = await registerUser(app.prisma, parse(RegisterInput, req.body));
    await startSession(reply, user.id);
    return reply.status(201).send({ data: { user } });
  });

  app.post('/auth/login', { config: limited }, async (req, reply) => {
    const user = await loginUser(app.prisma, parse(LoginInput, req.body));
    await startSession(reply, user.id);
    return { data: { user } };
  });

  app.post('/auth/logout', async (req, reply) => {
    const token = req.cookies[SESSION_COOKIE];
    if (token) await deleteSession(app.prisma, token);
    reply.clearCookie(SESSION_COOKIE, { path: '/' });
    return { data: { ok: true } };
  });

  app.get('/auth/me', { preHandler: requireAuth }, async (req) => {
    const user = currentUser(req);
    const family = await app.prisma.family.findUniqueOrThrow({
      where: { id: user.familyId },
      select: { id: true, name: true, baseCurrency: true },
    });
    return { data: { user, family } };
  });
};
```

```ts
    .refine((n) => n.toLowerCase() !== 'shared', '"Shared" is reserved for family-wide transactions'),
});

export type MemberDto = { id: string; name: string; isUser: boolean };

const toDto = (m: { id: string; name: string; userId: string | null }): MemberDto => ({
  id: m.id,
  name: m.name,
  isUser: m.userId !== null,
});

async function assertNameFree(prisma: PrismaClient, familyId: string, name: string, exceptId?: string) {
  const members = await prisma.familyMember.findMany({ where: { familyId }, select: { id: true, name: true } });
  if (members.some((m) => m.id !== exceptId && m.name.toLowerCase() === name.toLowerCase())) {
    throw new AppError(409, 'MEMBER_EXISTS', 'A family member with this name already exists');
  }
}

async function getOwned(prisma: PrismaClient, familyId: string, id: string) {
  const member = await prisma.familyMember.findFirst({ where: { id, familyId } });
  if (!member) throw notFound('Family member');
  return member;
}

export async function listMembers(prisma: PrismaClient, familyId: string): Promise<MemberDto[]> {
  const members = await prisma.familyMember.findMany({ where: { familyId }, orderBy: { createdAt: 'asc' } });
  return members.map(toDto);
}

export async function createMember(prisma: PrismaClient, familyId: string, name: string) {
  await assertNameFree(prisma, familyId, name);
  return toDto(await prisma.familyMember.create({ data: { familyId, name } }));
}

export async function updateMember(prisma: PrismaClient, familyId: string, id: string, name: string) {
  await getOwned(prisma, familyId, id);
  await assertNameFree(prisma, familyId, name, id);
  return toDto(await prisma.familyMember.update({ where: { id }, data: { name } }));
}

export async function deleteMember(prisma: PrismaClient, familyId: string, id: string) {
  const member = await getOwned(prisma, familyId, id);
  if (member.userId) {
    throw new AppError(400, 'MEMBER_IS_USER', 'This member is linked to a login and cannot be deleted');
  }
  await prisma.familyMember.delete({ where: { id } });
}
```

```ts
export function formatMoney(cents: number, currency = 'EUR', locale = 'de-DE'): string {
  return new Intl.NumberFormat(locale, { style: 'currency', currency }).format(cents / 100);
}

/**
 * Parses user-typed amounts like "52,40", "1.234,56", "1,234.56" or "5416 €" into cents.
 * The last "." or "," followed by 1–2 digits is the decimal separator; any other separators
 * must be a single kind of thousands separator in groups of three. Returns null if invalid.
 */
export function parseMoneyInput(input: string): number | null {
  const match = input.replace(/[\s€$£₹]/g, '').match(/^(-?)([\d.,]+)$/);
  if (!match) return null;
  const [, sign, body = ''] = match;

  const lastSep = Math.max(body.lastIndexOf('.'), body.lastIndexOf(','));
  let intPart = body;
  let frac = '';
  if (lastSep !== -1 && body.length - lastSep - 1 <= 2) {
    intPart = body.slice(0, lastSep);
    frac = body.slice(lastSep + 1);
    if (frac === '') return null;
  }

  const groups = intPart.split(/[.,]/);
  if (groups.some((g) => g === '')) return null;
  if (groups.length > 1 && (groups[0]!.length > 3 || groups.slice(1).some((g) => g.length !== 3))) {
    return null;
  }
  const thousandSeps = new Set(intPart.replace(/\d/g, ''));
  if (thousandSeps.size > 1) return null;
  if (frac && thousandSeps.has(body[lastSep]!)) return null;

  const cents = Number(groups.join('')) * 100 + Number(frac.padEnd(2, '0'));
  if (!Number.isSafeInteger(cents)) return null;
  return sign ? -cents : cents;
}
```

```ts
export class ApiError extends Error {
  constructor(
    public readonly status: number,
    public readonly code: string,
    message: string,
    public readonly details?: unknown,
  ) {
    super(message);
  }
}

async function request<T>(method: string, path: string, body?: unknown): Promise<T> {
  const res = await fetch(`/api${path}`, {
    method,
    credentials: 'same-origin',
    headers: body !== undefined ? { 'Content-Type': 'application/json' } : {},
    body: body !== undefined ? JSON.stringify(body) : undefined,
  });
  const text = await res.text();
  let json: { data?: T; error?: { code: string; message: string; details?: unknown } } | null = null;
  try {
    json = text ? JSON.parse(text) : null;
  } catch {
    json = null;
  }
  if (!res.ok) {
    const err = json?.error;
    throw new ApiError(
      res.status,
      err?.code ?? 'HTTP_ERROR',
      err?.message ?? `Request failed (${res.status})`,
      err?.details,
    );
  }
  return json?.data as T;
}

export const api = {
  get: <T>(path: string) => request<T>('GET', path),
  post: <T>(path: string, body: unknown = {}) => request<T>('POST', path, body),
  put: <T>(path: string, body: unknown) => request<T>('PUT', path, body),
  del: <T>(path: string) => request<T>('DELETE', path),
};

export function errorMessage(err: unknown): string {
  if (!(err instanceof ApiError)) return 'Something went wrong';
  if (Array.isArray(err.details) && typeof err.details[0]?.message === 'string') {
    return err.details[0].message;
  }
  return err.message;
}
```

```tsx
function MembersCard() {
  const queryClient = useQueryClient();
  const members = useQuery({ queryKey: ['members'], queryFn: () => api.get<Member[]>('/members') });
  const [name, setName] = useState('');
  const refresh = () => queryClient.invalidateQueries({ queryKey: ['members'] });
  const add = useMutation({
    mutationFn: () => api.post<Member>('/members', { name }),
    onSuccess: () => {
      setName('');
      return refresh();
    },
  });

  return (
    <Card title="Family members">
      <p className="mb-4 text-sm text-slate-500">
        Members let you see who spent what. Transactions without a member count as “Shared”.
      </p>
      {members.isPending ? (
        <p className="text-sm text-slate-500">Loading…</p>
      ) : (
        <ul className="divide-y divide-slate-200 dark:divide-slate-800">
          {members.data?.map((m) => <MemberRow key={m.id} member={m} onChanged={refresh} />)}
        </ul>
      )}
      <form
        className="mt-4 flex gap-2"
        onSubmit={(e) => {
          e.preventDefault();
          add.mutate();
        }}
      >
        <Input aria-label="New member name" placeholder="e.g. Spouse" value={name} onChange={(e) => setName(e.target.value)} />
        <Button type="submit" disabled={!name.trim() || add.isPending}>
          <Plus size={16} aria-hidden /> Add
        </Button>
      </form>
      <div className="mt-2">
        <FormError error={add.error} />
      </div>
    </Card>
  );
}

function MemberRow({ member, onChanged }: { member: Member; onChanged: () => Promise<void> }) {
  const [editing, setEditing] = useState(false);
  const [name, setName] = useState(member.name);
  const rename = useMutation({
    mutationFn: () => api.put(`/members/${member.id}`, { name }),
    onSuccess: async () => {
      setEditing(false);
      await onChanged();
    },
  });
  const remove = useMutation({
    mutationFn: () => api.del(`/members/${member.id}`),
    onSuccess: onChanged,
  });

  return (
    <li className="py-3">
      {editing ? (
        <form
          className="flex gap-2"
          onSubmit={(e) => {
            e.preventDefault();
            rename.mutate();
          }}
        >
          <Input aria-label="Member name" value={name} onChange={(e) => setName(e.target.value)} autoFocus />
          <Button type="submit" disabled={!name.trim() || rename.isPending}>Save</Button>
          <Button variant="secondary" onClick={() => { setEditing(false); setName(member.name); }}>
            Cancel
          </Button>
        </form>
      ) : (
        <div className="flex items-center justify-between gap-3">
          <span className="flex items-center gap-2 text-sm">
            <UserRound size={16} className="text-slate-400" aria-hidden />
            {member.name}
            {member.isUser && <span className="rounded bg-slate-100 px-1.5 py-0.5 text-xs text-slate-500 dark:bg-slate-800">you</span>}
          </span>
          <span className="flex gap-1">
            <Button variant="ghost" aria-label={`Rename ${member.name}`} onClick={() => setEditing(true)}>
              <Pencil size={16} aria-hidden />
            </Button>
            {!member.isUser && (
              <Button
                variant="ghost"
                aria-label={`Remove ${member.name}`}
                disabled={remove.isPending}
                onClick={() => {
                  if (window.confirm(`Remove ${member.name}? Their transactions will become “Shared”.`)) remove.mutate();
                }}
              >
                <Trash2 size={16} className="text-rose-600" aria-hidden />
              </Button>
            )}
          </span>
        </div>
      )}
      <div className="mt-2 empty:hidden">
        <FormError error={rename.error ?? remove.error} />
      </div>
    </li>
  );
}
```

```dockerfile
COPY package.json package-lock.json ./

COPY frontend/package.json frontend/

USER node
```
